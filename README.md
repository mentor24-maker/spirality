# Alphire Spirality

The AI development system: the shared loop that builds StarCaster, WaveCenter
and itself. One ClickUp door, one runner, one set of skills, one definition of
done, parameterised by a project config so every project runs the same loop
and every lesson lands once.

Start with `CLAUDE.md`, then `docs/LOOP_ENGINEERING.md`.

Putting a new project on Spirality: [`docs/ONBOARDING_A_PROJECT.md`](docs/ONBOARDING_A_PROJECT.md),
the checklist of everything it needs and what is still missing.

## 2026-11-02 — Make the 'go' command a button (#65)

Every ticket the intake loop writes up lands in Needs your input with the
same question: reply "go" to queue it, or say what to change. Dane was
typing "go" by hand each time. Now the ticket page shows a green **Go**
button, with the Merge button's look and 10px rounded corners, above the
reply box on exactly those tickets. One click and one confirm post "go" as
his reply, and the relay queues the ticket the way it always has.

The button only appears when the newest card really asks for "go" and ends
"Your move: Reply"; it never shows on Ready to launch (where "go" could
read as a merge word) or on a card asking something else. The word itself
lives in one place in the shared code and the server hands it to the page,
so the page can never post a word the loop does not expect.

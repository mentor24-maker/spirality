## 2026-11-13 — New Top Menu item: Topics (#221)

The tracker now has a **Topics** item in its top menu, right after Tasks.
A topic is a key aspect of a project, usually a feature. This is the first
piece of Dane's Topics series: a place where topics can be created and seen.

The Topics page shows the picked project's topics, newest first, with who
made each one and when. Underneath is a short form for adding a new one,
which needs a name and can have a description. Each topic belongs to one
project, so a topic made in Alpha never shows up on Beta's page. Anyone who
cannot see a project cannot see or add its topics, the same rule the Docs
page follows.

The page checks its own work. A blank name is turned down before anything
is sent. After a topic is created, the page reads the list again and only
says "Created" if the new topic is really there. If something fails, the
page says so in red.

Linking topics to tasks and to each other, and editing or deleting them,
come in the next tickets.

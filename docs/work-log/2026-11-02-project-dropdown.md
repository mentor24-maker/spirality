## 2026-11-02 — Make the 'Change Project' link a dropdown list of projects, with the current project selected. (#64)

Switching project on the Tasks page used to mean clicking "Change project", landing on the Projects page, and picking from there. Now the Tasks page itself shows "Project:" and a dropdown of every project, with the one you are looking at already chosen. Picking another opens it straight away in the same view, board or list, and the browser's Back button takes you to the one before. Nothing else on the page changed.

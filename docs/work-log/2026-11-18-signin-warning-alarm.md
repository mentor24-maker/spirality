## 2026-11-18 — Post an alarm a week before the Mini's Claude sign-in ends (#323)

The Mini's Claude sign-in has an end date, and when it passes every loop in
every project stops. Claude already said so on every pass, but only as a
warning line buried in each lane's log, so nothing reached Dane. Now the lane
runner reads each pass's output for that warning, and from a week before the
earliest end date it posts one alarm to the project's bus (which texts the
alert phone) naming the date and the two commands that fix it for good. It
says it at most once a day, tries again on the next pass if the post did not
land, and can never stop or change a pass.

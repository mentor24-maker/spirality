## 2026-11-10 — Update the header Stages pod (#159)

The little box on the Tasks page that shows when each loop runs next used to
squeeze all four stages onto one line, which was hard to read at a glance. It
now has a "Pipeline Stages" heading and lists Relay, Build, Review and Intake
one per row, with the names in bold and the times lined up beside them. A

light blue as the page's other notes. Clicking it still opens the full
Pipeline Status window, and screen readers still read every stage.

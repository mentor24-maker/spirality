## 2026-11-10 — Updates to the Docs page (#172)

The Docs page used to open with a long, flat list of every file in the
repository's `docs/` folder, under the vague name "Spirality Documentation".
Those files are not attached to tasks: they are the reference documents (the
loop contract, the plan, the doctrine and so on), two onboarding guides, and
the work log, which gets one short entry like this one for every pull request
that merges.

So the list is now called **Reference Docs and Work Log**, and it is easier
to find your way through. Each file shows its kind (Reference, Onboarding or
Work Log) and, for work-log entries, the day it was written. Clicking Title,
Kind or Date sorts the list, and clicking again reverses it. A Kind drop-down
and a search box at the top narrow the list together, with a line saying how
many are showing. The whole section starts folded shut and sits at the bottom
of the page, below Commands, so the project's own files come first.

## 2026-11-10 — Make all screens 1440px wide (#154)

The tracker's pages were two different widths. The Tasks page (the Board and
the List) stretched across the whole window, and every other page (a ticket,
Projects, Users, Search) sat in a narrower column about 960 pixels wide, so the
page jumped in width every time Dane moved between them.

Now every page uses one column, at most 1440 pixels wide and centred, with the
same blank margin on both sides on a big screen. On a smaller window the page
still fills it as before. The Tasks page's special "full width" setting is
gone, so no page can drift to a width of its own, and a new check fails if
anyone brings one back. On a very wide screen the Board now shows about five
columns at a time and the rest scroll sideways, which was the accepted trade.

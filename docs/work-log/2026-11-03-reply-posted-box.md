## 2026-11-03 — When I submit a response on a task, display message (#78)

Posting a reply on a task's page used to throw Dane down to the bottom of the
comment thread, away from the title and buttons he was looking at. Now the
page stays where it is, at the top, and a small box pops up over it saying
"Your reply was posted." He closes it with OK or the Escape key. The Merge,
Close and Go buttons work the same way, since they post his word through the
same path. If a post fails, there is no box: the red "Not posted" note beside
the button says what went wrong, as before. Nothing about what gets stored
changed; the reply is still saved exactly as typed.

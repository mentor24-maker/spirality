## 2026-11-01 — Reporting section (#55)

The tracker has a new **Reporting** item in its header menu. It opens a page
that answers the first questions Dane asked about how the work is going:
how many tasks were finished in the last week, the last month and all time;
how many new tasks were started in those same stretches; and how many are
sitting in each stage right now, each stage in the colour he picked on the
Settings page. A picker at the top switches between one project and all of
them.

The counts come from the tracker's own record of every status change, so a
task that was marked finished and then sent back is not counted as done,
and one finished twice counts once. The page itself only shows the numbers
the tracker works out, the same way the other pages do.

This is the first of four pieces. The next ones add reports on how work
flows (how long tasks take, how often they come back) and the one Dane
singled out: how many hours of a human programmer's time the finished work
stands for.

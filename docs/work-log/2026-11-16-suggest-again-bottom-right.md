## 2026-11-16 — Move the Suggest Again button to the bottom right of the Suggest screen (#272)

On the Tasks page, the Add Task box can suggest the project's next tasks. Once
the suggestions came back, the button that asks for a fresh set (Suggest
Again) still sat at the top, far from the button that files the chosen ones.
Now, while suggestions are showing, Suggest Again sits on the bottom row,
pushed to the right, across from File in This Order. That puts the two choices
you make after reading the list side by side. Before anything has been
suggested, or after a run that failed, the button is back at the top as
Suggest Next Tasks or Try Again, as before. It is still one button that simply
moves, so what it does and when it is greyed out haven't changed. The line
saying how a run is going stays at the top. On a narrow window the bottom row
wraps instead of squashing the buttons.

## 2026-11-13 — Reporting page updates (#208)

The first table on the Reporting page used to be called "Tasks Finished and
Started", with finished tasks on the top row. Dane asked for it to be called
**Task Productivity**, with tasks started on top and tasks finished below. That
is what this change does, and nothing more: every number is worked out exactly
as before, so the figures on the page are the same, just in the new order. The
note under the heading now names Started first to match, and the two places in
the docs that called the table "Finished and Started" now use the new name.

This is the first of three slices of Dane's request. The next two add a custom
date range (SP-240) and a growth rate column (SP-241) to the same table.

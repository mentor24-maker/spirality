## 2026-11-27 — Add the operator hand-off Stop hook that refuses pasted commands for Dane (#345)

A standing rule says agent sessions run the commands themselves and only hand Dane something for a real secret value, a billing screen, a browser login or a decision that is genuinely his. In Spirality that rule was only written down. StarCaster learned that a written rule gets broken, so it built a tripwire: a small script Claude Code runs whenever a session is about to finish its reply. If the reply hands Dane a ready-to-paste command and does not say which of the four exceptions applies, the reply is sent back and the session is told to run the command itself.

That tripwire now runs in Spirality too, moved across with its tests. The only changes are the ones Spirality needs: the message points at Spirality's own rules, and the one check that named StarCaster's folder now reads the folder of whatever repository the session is in. Its safety brakes came across untouched: it only acts in sessions started at a terminal (the unattended lanes are never touched), it steps aside if it cannot read the reply, and it gives up after three refusals so it can never trap a session.

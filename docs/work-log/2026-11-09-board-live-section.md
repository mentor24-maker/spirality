## 2026-11-09 — The Board's Live column crowds out the working columns: show Live as its own section below the Board (#132)

Finished tickets used to sit in a Live column at the far right of the Board.
Live only ever grows, so that column took room from the stages where work is
actually moving. Now the Board shows only the working stages as columns, and
Live is its own section underneath, drawn the same way as on the List view:
its count in the heading, one row per finished ticket with the newest change
at the top, and each row opens its ticket. The List view did not change.

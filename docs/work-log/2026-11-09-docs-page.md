## 2026-11-09 — Create a new main menu item named 'Docs' right after Users (#147)

Until now, a file attached to a task could only be found by opening that
task. The tracker's menu now has **Docs**, between Users and Settings, and
it opens one page listing every file on every task in the project you have
picked: the file's name (click it to download), which task it belongs to
(click to open the task), what kind of file it is, how big, who added it and
when, newest first. If a project has no files yet, the page says so.

Only people on a project can see its files; anyone else gets the same "not
found" answer as for a project that does not exist. Nothing can be changed
from this page yet: it is the first of four steps, and the next ones add
Spirality's own documentation, a project's context documents, and adding,
renaming and removing files.

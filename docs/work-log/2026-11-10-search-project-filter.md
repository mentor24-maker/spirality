## 2026-11-10 — Task search needs a filter for project (#157)

Searching for a word on the tracker used to mix every project's tickets together, with no way to say "only this one". The Search page now has a **Project** picker at the front of its filter row: "Any" for everything, or one project by name. Searching from the Tasks page starts with the project you were already looking at, and you can widen it back to "Any" in one click.

Someone who is only on some projects is offered only those, and asking for another one by typing it into the address gets the same "there is no project" answer as a made-up name, so the search never gives away a project they are not on.

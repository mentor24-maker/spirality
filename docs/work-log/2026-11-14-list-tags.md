## 2026-11-14 — Change a ticket's tags from the Tasks list (#231)

On the Tasks page's List view, a ticket's tags can now be changed straight from its row, the same way its priority and who it is assigned to already could. Each tag has a small × to remove it, and an Add Tag dropdown offers the tags already used in that project (so the same tag is not spelled three ways), with New Tag… for a fresh one.

It saves the way the ticket's own page does, with the same check that a loop has not changed the ticket in the meantime, so a change made from the list can never quietly overwrite a loop's move. While one save is running, the other dropdowns on the list wait for it, so two changes cannot cross.

## 2026-11-16 — Add a clickable diagram to the Docs page linked to a new Loop Queue Anatomy page (#280)

Dane drew a diagram of the Loop Queue: the eight statuses a ticket moves
through, with labelled arrows between them. He asked for it on the Docs page,
with each box opening a page that explains that status. This is the first half
of that work. The new **Loop Queue Anatomy** page has one section of about 200
words for each box. Each section says what the status means, who looks after it,
and what moves a ticket in and out. All of it comes from the loop's rulebook,
`docs/LOOP_CONTRACT.md`.

So that clicking a box can open the page right at its section, every heading on
a documentation page now has its own web address, made from its words: adding
`#rework` to the address opens the page at Rework. Ticket descriptions are left
exactly as they were. The second half, putting the picture on the Docs page with
each box as a link, is its own ticket and waits on this one.
